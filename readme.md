## 📸 InstaClone - Instagram Clone Web App

InstaClone is a full-featured Instagram-like web application built using **EJS**, **MongoDB**, **Node.js**, and **Express.js**. This project replicates key functionalities of Instagram, offering a seamless user experience with profile management, image sharing, and social interactions.

---

## 🌟 Features

* 🔐 **Login & Register**
  Secure authentication system for new and returning users.

* 🏠 **Feed Page**
  View posts from all users, just like the main feed on Instagram.

* 👤 **Profile Page**
  Displays user information, profile picture, and shared posts.

* 📷 **Picture Upload**
  Users can upload photos to share with others.

* 📖 **Story Feature**
  Upload and view temporary stories similar to Instagram Stories.

* ✏️ **Edit Profile Details**
  Update name, bio, and profile picture.

* 🔄 **Share to Story**
  Easily share posts directly to stories.

* 🔍 **Search Accounts**
  Find other users and explore their profiles.

---

## 🧰 Tech Stack

* 🖼️ **EJS** – Server-side templating
* 🌿 **MongoDB** – Database
* 🟩 **Node.js** – Runtime environment
* 🚂 **Express.js** – Backend framework

## ⚙️ Setup Instructions

1. **Clone the Repository**

```bash
git clone https://github.com/your-username/instaclone.git
cd instaclone
```

2. **Install Dependencies**

```bash
npm install
```

3. **Configure Environment Variables**
   Create a `.env` file in the root directory and add your MongoDB URI and other configuration settings:

```
MONGO_URI=your_mongodb_uri
SESSION_SECRET=your_secret_key
```

4. **Start the App**

```bash
npm start
```

Your app will be running at `http://localhost:3000`
